RecipeHub — учебное веб-приложение для публикации, поиска и оценки рецептов.
Проект разработан в рамках курсовой работы по дисциплине **Веб-разработка**.

---

## Описание проекта

Приложение позволяет пользователям:
- просматривать рецепты;
- добавлять собственные рецепты;
- оценивать и комментировать рецепты;
- добавлять рецепты в избранное.

Реализована система ролей и авторизации с использованием Spring Security.

---

## Используемые технологии

- Java 17
- Spring Boot
- Spring MVC
- Spring Data JPA
- Spring Security
- PostgreSQL
- Redis (кэширование)
- Thymeleaf
- Maven
- Hibernate

---

## Роли пользователей

- **USER**
  - регистрация и авторизация
  - добавление рецептов
  - комментарии и оценки
  - избранные рецепты

- **ADMIN**
  - все возможности пользователя
  - удаление рецептов
---
## Основной функционал
- CRUD для рецептов
- Фильтрация и поиск рецептов
- Оценки и средний рейтинг
- Топ-3 популярных рецепта на главной странице
- Избранное
- Комментарии
- Кэширование популярных данных
- Валидация данных
- Защита страниц по ролям
